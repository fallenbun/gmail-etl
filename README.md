# Персональная ETL‑аналитика чеков из Gmail

Автоматизируем сбор, хранение, моделирование и анализ данных о покупках, которые приходят на почту в виде электронных чеков.

> **Цель:** показать полный цикл работы с данными:  
> сбор (Gmail API) → хранение сырых данных (JSON) → загрузка в хранилище (PostgreSQL) → трансформация (dbt) → визуализация и аналитика (Jupyter / Metabase).

---

## Стек технологий

Python 3.11+, Gmail API, PostgreSQL, dbt Core
