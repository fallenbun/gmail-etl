## О проекте

Проект предназначен для автоматического сбора, структурирования и анализа электронных чеков, которые приходят на почту Gmail в виде HTML-писем.

В основе проекта лежит идея: получать данные о покупках без ручного импорта, сохранять их в хранилище и использовать для аналитики, визуализации и мониторинга финансовой активности.

| Контейнеризация | Docker / Docker Compose | Запуск всей инфраструктуры проекта |

### Как работает пайплайн

Процесс выглядит следующим образом:

1. Скрипт получает непрочитанные письма от конкретного отправителя.
2. Из письма извлекается HTML-тело.
3. Модуль `ReceiptParser` анализирует документ и распаковывает данные чека:
   - идентификатор чека;
   - дата и время покупки;
   - общая сумма;
   - данные магазина;
   - список товаров и их атрибуты.
4. Итоговые записи сохраняются в таблицы raw-слоя.
5. dbt распаковывает сырой JSON, подготавливает и приводит данные к модели Data Vault 2.0.
6. Apache Airflow управляет запуском задач и координирует ETL-процесс.

### Основные модули

- `src/gmail_client.py` — работа с Gmail API и чтением писем
- `src/receipt_parser.py` — парсинг чека из HTML
- `src/loader.py` — загрузка в БД
- `airflow/dags/` — оркестрация ETL
- `dbt/models/` — преобразования и модели данных

## Настройка проекта и запуск

### 1. Подготовка Google OAuth

Для Gmail API необходимы:

- файлы OAuth-данных;
- токен авторизации;
- настройки доступа в Google Cloud.

Ожидаемые пути:

- `src/auth/credentials.json`
- `src/auth/token.json`

См. [руководство GmailAPI](https://developers.google.com/workspace/gmail/api/quickstart/python?hl=ru)

### 2. Запуск сервисов

```bash
docker compose up -d
```
