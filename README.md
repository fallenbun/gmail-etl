# Импорт электронных чеков из почты Gmail

Небольшой проект по сбору и анализу данных покупок, которые приходят на почту в виде электронных чеков.

## Цель проекта
Проследить динамику собственных трат и параллельно изучить современный стек технологий.

## Этапы разработки
- Получение писем через Gmail API
- Извлечение данных чека из тела письма методом парсинга HTML
- Запись сырых данных в БД PostgreSQL в формате JSON
- [**PROCCESS**] Распаковка JSON, дедупликация и моделирование данных по методологии Data Vault 2.0 при помощи dbt Core
